# Phone model reference images

Each of the 243 repair-directory models is matched explicitly by brand and full model name in src/modelPhotoData.mjs. No fuzzy or shared brand-photo fallback is used. Each entry retains the source page and source model label. Checked 7 November 2026; all image URLs returned an image successfully.

- Apple: official identification images from https://support.apple.com/en-gb/108044 . SE generations are explicitly mapped to their corresponding catalogue year.
- Samsung and Google: model-specific product imagery indexed by https://github.com/bytecharts/device_specs_gsmarena, with the originating GSMArena pictures page retained for each model. Explicit source-name equivalents preserve 5G and historical model-number labels; a Pro, Plus, Ultra, mini or Max is never substituted for another size.
- Newer Samsung devices: official Samsung product and newsroom pages; source per entry.
- Pixel 11, 11 Pro and 11 Pro Fold: official Google Store images, selected using the matching model's image description.
- Pixel 11 Pro XL: exact-model product reference from Vanden Borre; source per entry.

Images remain hosted by their original sources. Copyright belongs to the respective rights holders; these are model identification references, not iTop stock photographs or a claim of manufacturer endorsement. The repair-page image source is linked visibly. Colours can differ. Cards load lazily; unavailable images show a neutral notice rather than another phone.
